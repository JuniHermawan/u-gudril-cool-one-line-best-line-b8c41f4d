One line, 101 characters: a bus driver waves at a stranger, the stranger waves back, and neither of them has any idea who the other one is. The program keeps a shortlist of candidate lines, scores each against the judge's own yardsticks — on-theme first, then scroll-stop, genuinely entertaining, one sentence with a punch at the end, and fresh — and writes the strongest line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
